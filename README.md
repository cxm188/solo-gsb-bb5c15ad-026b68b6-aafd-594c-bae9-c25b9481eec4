# 圆筒包装接缝避让

输入筒体周长、接缝安全宽度与若干毫米制印刷保护区，系统按周长归一化跨零点区间、合并禁用旋转范围、列出全部可行角度段，并默认选择距禁用边界最远、角度最小的旋转量。Canvas 同步预览接缝与保护区，拖动时吸附到最近可行位置；无解时展示覆盖整圈的禁用区间链。

## 设备档位约束

单规格与多规格模式均可勾选「启用设备档位约束」，填写**每圈档位数**（2～360 的整数）与**零位偏移**（角度，可负、可超 360°，自动按整圈归一）。启用后系统只允许角度

```
θ = 零位偏移 + n × 360° / 档位数 （按整圈归一到 0°–360°）
```

- 档位网格与当前**可行段**（单规格）或**共用段**（多规格）求交，右栏列出**全部可用档位**及各档位的瓶颈间隙（多规格同时列出每个规格下的实际间隙与毫米位置）。
- **默认档位**沿用现有规则：瓶颈间隙（到最近禁用边界的圆周角距离）最大，并列时取角度较小者；恰好落在可行段边界上的档位视为可用、间隙为 0。
- **连续区间有解但没有可用档位**时，与「保护区覆盖整圈」明确区分：黄色提示框给出**距可行段最近的前一档（逆时针）与后一档（顺时针）**及其角距离、所贴近的可行段边界，Canvas 上以橙点标出；此时当前位置线显示为橙色，拖动不会吸附到禁用档位。
- Canvas 上全部档位画细刻度，可用档位以绿点标记；**拖动只能吸附到可用档位**，点击可行段/共用段也会吸附到该段内最近的可用档位。
- 取消勾选即关闭约束，计算与吸附恢复为连续行为；**档位数与零位偏移输入在勾选切换与单/多模式切换时均保留，不会清空**。
- 单规格快照会一并保存档位参数；载入含档位的快照时自动恢复勾选与输入。

## 多规格共用角度模式

顶部切换到「多规格共用角度」后，可输入 **2～8 个筒体周长**，沿用同一接缝安全宽度与同一组毫米制保护区：

- 系统对每个规格分别计算，再把各规格可行段统一到角度域 **0°–360°** 求圆周交集，输出**所有规格均安全的共用角度段**（跨零点自动合并展示）。
- **默认共用角度**：对候选角度 θ 取其在各规格下到禁用边界的圆周角距离的最小值并最大化（即瓶颈间隙最大），平局时取较小角度；右栏列出该角度在每个规格下的实际间隙与对应毫米位置。
- **无共同解**时，按规格输入顺序定位使公共交集**首次归零**的规格，列出该规格及其禁用区间与此前公共段的**冲突区间**，Canvas 上以红虚线标出。
- Canvas 由外向内**叠加每个规格的禁用环**（颜色对应规格序号），绿色环为共用安全段；拖动时吸附到最近的共用安全角度。
- 切回「单规格模式」时，单规格的周长与多规格周长列表均保留在页面中，**不会丢失任何已输入内容**。
- 方案快照仅保存单规格结果，多规格模式下快照入口自动禁用。

## 方案快照

- 在「方案快照」面板可为**当前周长、接缝宽度与保护区计算结果**命名并保存；快照按时间倒序列出，支持载入参数与删除。
- 勾选两个快照（依次标记为 A、B）后点击比较：系统将三类圆周区间（保护区、合并禁用段、可行段）统一归一化到 **0°–360°**，即使两个快照周长不同也可比较。
- 差异输出：
  - **新增**（B 有 A 无，绿色）／**移除**（A 有 B 无，红色）的圆周区间；
  - **边界移动**（紫色）：按重叠最大配对对应段，给出起点/终点沿最短圆弧的有向位移（顺时针 +、逆时针 −），跨零点自动取短弧；
  - 共有的部分以灰色底环显示。
- 差异 Canvas 上三个环分别对应可行段（外）、禁用段（中）、保护区（内），右栏列出逐段明细（角度，并附各快照周长下的毫米参考值）。
- 快照数据保存在浏览器 **localStorage**（键 `seam-avoidance:snapshots:v1`，最多 100 个），不经过服务器；清除浏览器数据即删除。重新计算或「返回实时预览」即回到原有实时预览。

## API

| 方法 & 路径 | 说明 |
| ----------- | ---- |
| `POST /api/compute` | 单规格计算。请求体：`{circumference, seamWidth, zones:[{start,end}], gear?}`（单位 mm） |
| `POST /api/compute-multi` | 多规格共用角度。请求体：`{circumferences:[…2～8 个周长…], seamWidth, zones, gear?}`；返回每个规格的完整单规格结果（`specs[].result`）、圆周交集 `common`（角度弧段）、默认角度 `best.deg` 及各规格间隙 `best.gaps`；无共同解时 `noSolution=true` 并给出 `blocker`（首次归零的规格序号、此前公共段 `priorCommon`、该规格禁用段 `blockingForbidden` 与冲突区间 `conflictSegments`） |
| `GET /api/health` | 健康检查 |

### 档位参数 `gear`

缺省或 `null` 表示不启用；也可显式传 `{enabled:false}`。启用时：

```json
{ "enabled": true, "positions": 12, "offsetDeg": 0 }
```

- `positions`：每圈档位数，必须为 **2～360 的整数**，否则返回 `400`；
- `offsetDeg`：零位偏移（°），可负、可超界，服务端归一到 `[0,360)`；非数值返回 `400`。

响应中的 `gear` 对象：

- `positions` / `offsetDeg`：归一化后的档位配置；
- `usable[]`：落在可行（共用）段内的档位 `{index, deg, gapDeg, …}`——`gapDeg` 为到最近禁用边界的瓶颈间隙（`null` 表示无禁用边界）；单规格另含 `mm`，多规格另含 `gaps[]`（各规格间隙与毫米位置）；
- `best`：默认档位（瓶颈间隙最大、并列角度较小）；
- `nearest`：连续区间有解但无可用档位时，`{before, after}` 各为距可行段最近的前/后档位 `{index, deg, distanceDeg, boundaryDeg}`；其余情况为 `null`；
- `allGears[]`：整圈禁用/公共交集归零时列出的理论档位（均不可用）。
